# business-sales-analyzer
A Python-based sales analytics dashboard that cleans uploaded data, analyzes revenue and profit trends, and creates interactive charts by product, region, and time.

# Sales Analytics Dashboard

A Python project that analyzes sales data and displays the results in a Streamlit dashboard.

## Features

- Reads sales data from an Excel file
- Calculates total revenue, cost, profit, and quantity sold
- Groups sales by product and region
- Identifies top-performing products
- Shows sales trends over time
- Creates charts for the analysis

## Project files

- `app.py` - main Streamlit app
- `analysis.py` - sales calculations and analysis
- `charts.py` - chart creation
- `data_processing.py` - loads and prepares the data
- `sample_sales.xlsx` - sample dataset

## Built with

- Python
- pandas
- Streamlit
- openpyxl

## Run the project

```bash id="ro26or"
streamlit run app.py
```
